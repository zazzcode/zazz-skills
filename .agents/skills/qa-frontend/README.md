# Frontend QA Skill — User Guide

How to use the Frontend QA specialization for deliverables with meaningful UI or browser-facing scope.

## What It Does

`qa-frontend` extends the base `qa` skill with frontend-focused verification.

It adds emphasis on:
- user journey validation
- UI state and interaction behavior
- accessibility checks
- viewport and browser coverage
- frontend standards and code-quality patterns

## When to Use It

Use this skill when the deliverable includes:
- new or changed UI flows
- forms, modals, navigation, or interaction-heavy work
- client-state changes
- accessibility-sensitive changes
- frontend integration behavior

## How to Use It

Use it together with the base `qa` skill.

Example:

```text
Use qa and qa-frontend.
This deliverable changes a major UI flow and accessibility-sensitive components.
Please run a frontend-focused QA pass and create rework content for anything that fails.
```

## Output

In addition to the base QA output, this skill should add:
- UI journey verification notes
- accessibility findings
- browser and viewport coverage notes
- frontend-specific PR evidence

## Notes

- This is a specialization, not a replacement for `qa`.
- It is especially useful when owner sign-off is needed for layout, interaction feel, or UI acceptance criteria.
